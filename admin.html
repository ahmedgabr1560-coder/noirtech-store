• الاسم والأيقونة — اسم المتجر والشعار

• الواجهة — صور ونصوص أول صفحة + الدفع

• الأقسام — إظهار/إخفاء أي قسم أو فرع

• المنتجات — إضافة / تعديل / إخفاء / حذف

• أكواد الخصم والشحن والأرباح
